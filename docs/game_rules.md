# Canonical v1.0 Game Rules & Contract (A1 & Orchestrator Freeze)

## 1. Scope & Genre
- **Title:** 《高高平等：人人有輪坐》
- **Genre:** 輕量級市政諷刺模擬 (Lightweight Political-Administrative Satire)
- **Visuals:** 2D 復古辦公桌介面 + 3D 低多邊形 (Low-Poly) 微縮沙盤模型 (Diorama)
- **Duration:** 12 回合 (4 個章節：愛情起飛、高高平等、摩天輪失控、愛情驗收)
- **Tech Stack:** Vanilla JavaScript (ES Module), HTML5, CSS3, Three.js, Web Audio API

---

## 2. Five Fictional Zones & 3D Elevations
1. **⚓ 港灣區 (高度 0.5):** 深藍色水面，低矮倉庫。空間小，交通難外連。
2. **🏘️ 舊城區 (高度 1.0):** 灰色擁擠建築網格。空間不足，強蓋設施會穿模。特例：允許最多建造 3 座摩天輪 (解鎖「日照權是什麼」成就)。
3. **🚡 郊區發展區 (高度 1.5):** 淺綠色平坦草地。空間大但極度邊疆。
4. **🏙️ 科技區 (高度 2.0):** 霓虹藍半透明方塊陣列。招商條件多。
5. **⛰️ 山城區 (高度 4.0):** 陡峭深綠色幾何山體。制高點，交通可達性極低。與港灣區直連軌道將產生 80 度垂直軌道 (解鎖「牛頓的眼淚」成就)。

---

## 3. Global State & Deficit Mechanics
- **Budget (B):** 初始 24 億，每回合基礎收入 +2 億。
- **Debt (D):** 初始 0 億。建造貸款在建造當下限制總借貸 D ≤ 12 億。
- **Net Budget (NB):** `B - D`。以 LED 7 段數字顯示，允許負數 (赤字)。
  - **NB ≥ 10:** 階段 1，財政局長冷靜，一般公文便條。
  - **0 ≤ NB < 10:** 階段 2，螢光黃急件便條，電話鈴響，局長開始掉髮。
  - **NB < 0 (赤字災難):** 階段 3，醫療急診診斷書與點滴袋，心電圖逼逼聲。3D 地圖未完工設施張貼黃色「法院查封」封條，摩天輪發出金屬摩擦跳火花。
- **Admin Burden (A):** 0–100。螢幕四周貼滿黃色/粉紅色「急件」便利貼，數值越高遮擋視線越多。
- **Petition / Complaints (Q):** 0–100。數值過高時觸發大聲公震撼波、天空降下實體陳情書、摩天輪噴漆紅「X」。
- **Tourism (T):** 0–100。影響商圈經常性營運收入。

## 4. Player Major Actions (1 per Turn)

| Action | Cost (億) | Lead Turns | Immediate & Operating Effect |
|---|---:|---:|---|
| `wheel(zone)` | 8 | 2 | 完工後 T +8。營運收入 +1/回，維護費 −1/回。舊城區上限 3 座，其餘區上限 1 座。 |
| `shuttle(zone, to_zone)` | 3 | 0 | 完工後 T +2。維護費 −0.5/回。建立雙向交通連通圖。 |
| `market(zone)` | 3 | 1 | 完工後 T +3。若該區能連通至任一運作中的摩天輪，營運收入 +1/回。上限 1 座/區。 |
| `event(zone)` | 2 | 0 | T +5，Q −2。3D 地圖充氣巨型粉紅邱比特，回合結束後消氣被垃圾車拖走。 |
| `hearing()` | 1 | 0 | A −4，Q −7。抗議小人集體撲街沉睡 (Zzz)。累計 ≥ 5 次解鎖成就。 |
| `repay(amount)` | 上限現有現金 | 0 | 償還指定額度債務，消耗 1 次主要行動。 |
| `rest()` | 0 | 0 | 不進行建設，正常結算公文事件與經常收支。 |

## 5. Endings & Priorities (9 Total)

1. **Hidden S《愛情無價，市府破產》:** `tourism >= 75` 且 `complaints <= 35` 且 `budget - debt <= 0`。
2. **一城五輪:** 摩天輪總數 ≥ 4 且交通維護費大於商圈營收。
3. **預算追加申請中:** `debt > 0` 且 `budget < debt`。
4. **永遠開不完的協調會:** `admin >= 75`。
5. **全市愛情接駁網:** 連通 5 個行政區 且 接駁線 ≥ 3 條。
6. **摩天輪旁的夜市:** 商圈總數 ≥ 3 且 `tourism >= 60`。
7. **招商成功，命名失敗:** `tourism >= 70` 且 `complaints >= 55`。
8. **低調完成任務:** 連通 ≥ 4 個行政區 且 `debt == 0` 且 `complaints <= 40`。
9. **仍在協商中的愛情城市:** 未符合上述任一條件時之常規結尾。

## 6. Steam Achievements Criteria
1. **ACH01 牛頓的眼淚:** 建造直連「港灣區(0.5)」與「山城區(4.0)」之接駁路線。
2. **ACH02 無情的蓋章機器:** 連續 3 次公文在飛入後 1 秒 (1000ms) 內快速蓋章決行。
3. **ACH03 日照權是什麼:** 在舊城區建造 3 座摩天輪。
4. **ACH04 會議時空暫停之術:** 單局累計使用 `hearing` 行動 ≥ 5 次。
5. **ACH05 高科技賽博夜市:** 科技區擁有商圈與摩天輪，且在 EV21 選擇 A 接受企業冠名。
6. **ACH06 國庫精算大師:** 遊戲第 12 回合結束時，淨預算 (`budget - debt`) 剛好為 0。
