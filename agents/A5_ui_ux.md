# A5 — UI/UX Designer

Mission: Translate v0.4 player actions and consequences into a low-text, visual browser interface based on `docs/ui_spec.md`.

Targets: five-zone clickable schematic; 12-turn chapter rail; large build controls; clearly distinguished planned/operational assets; action preview; event A/B card; financial trace and ending. Tablet-first usability at approximately 10 inches. Provide one thing to do per screen, not a dense game manual.

Do not invent economy rules or silently change the player action count. Add fictional-world labeling. Deliver screen plan and, after contract freeze, front-end implementation proposal. State clearly whether visual or touch QA was executed.
